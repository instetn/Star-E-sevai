## How to upload to GitHub (GitHub Pages)

1. Go to https://github.com and sign in (create a free account if needed).
2. Click **New repository**. Name it `YOURUSERNAME.github.io` (replace with your GitHub username) and click **Create repository**.
3. Click **uploading an existing file** (or Add file → Upload files).
4. Drag **all files and folders** from this `star-esevai-website` folder (not the folder itself — its contents: index.html, css, img, etc.).
5. Click **Commit changes**.
6. Go to **Settings → Pages** → under "Branch" select `main` and `/ (root)` → Save.
7. After 1–2 minutes your site is live at `https://YOURUSERNAME.github.io`.

### Use your own domain (kovaihub.in)

In **Settings → Pages → Custom domain**, enter `www.kovaihub.in`, then at your domain provider add a CNAME record pointing `www` to `YOURUSERNAME.github.io`. Enable **Enforce HTTPS**.
